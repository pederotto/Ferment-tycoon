Fermenta Tycoon · design spike

Would isometric earn its art budget?

One bench, drawn as a scene instead of a grid of cards, in the palette the game already uses. The question is not whether it looks nicer — it is whether it can say things the current layout cannot.

The argument

A 60 L cask is three times the jar, and nothing on screen says so

Every vessel is currently a card of identical size. The only thing telling you an oak cask is thirty times a mason jar is the text 60L. Here they are at true relative scale — linear size as the cube root of volume, which is what your eye would actually see on a bench.

2 LMason jar
3 LKoji tray
10 LThermal chamber
20 LOnggi
50 LCedar barrel
60 LOak cask

Why it matters The upkeep bill, the stratification penalty and the fill button are all functions of volume. The player is asked to reason about litres constantly and has never once been shown them.

The proposal

The bench as a room, not a table

Four occupied slots on a cedar bench. Every vessel is still a DOM element, so hovering, clicking and keyboard focus work exactly as they do now — selecting one would open the inspector you already have, unchanged.

Hover or tab through a vessel

Still DOM Each slot is an SVG group with tabindex and a role. No hit-testing to build, no canvas event layer, screen readers still work — the things you lose the moment you reach for a game engine.

The real payoff

State you currently have to read, shown instead

The simulation already tracks all of this. Every one of these is a number in a panel today, and a number is the weakest way to teach someone what a ferment is doing.

What it would cost

An honest ledger

Medium SVG, hand-authored, same as JarVesselArt today. No new dependency, no asset pipeline, no build change. Everything above is one HTML file.
The real bill Six vessels redrawn, plus a bench and a floor. That is the whole cost, and it is art rather than engineering — a half-finished isometric bench looks considerably worse than the tidy grid you have now.
Scope One component. LabView becomes a scene; the inspector, order book, codex and titration bench are untouched and stay panels.
Stays flat Anything you read or type into. Nobody wants to drag an isometric slider to set salinity to 18.5%.
Not needed Pixi, Three, a canvas layer. Eight slots and six vessel types do not justify an engine, and buying one costs you DOM events and keyboard access.

The scale strip is the part to judge first. If seeing a 60 L cask next to a 2 L jar tells you something the card grid never did, the art is worth commissioning. If it does not, the rest of this is decoration and the current layout is fine.

Everything here is one throwaway page. Nothing has been changed in the game.
